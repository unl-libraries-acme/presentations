# UNL Libraries ACME Presentations

Slides and handouts from presentations by staff in the Acquisitions, Cataloging, Metadata, and Electronic Resources (ACME) department, University of Nebraska-Lincoln Libraries.

**Browse presentations:** https://unl-libraries-acme.github.io/presentations/

## Repository structure

Each presentation has its own folder, organized by year (for example, `2026/2026-10-btaa-hoa-standards-survey/`). Folders contain slides with and without speaker notes, plus any handouts.

## Adding a presentation

1. Upload the files to a new folder under the appropriate year.
2. Add an entry to `_data/presentations.yml`.
